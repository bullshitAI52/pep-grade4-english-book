# 四年级英语 PEP 下册

这是人教版（PEP）小学四年级英语下册的学习资源。

## 📚 内容

- **完整教材 PDF**: 包含全部90页教材内容（1-1 至 1-3 + 四年1 至 四年87）
- **单词表**: 从第80-87页提取的所有单词和翻译

## 📥 下载

### 方式一：直接下载 PDF
点击右侧 [Releases](../../releases) 查看并下载最新版本的 PDF 文件。

### 方式二：查看单词表
- [Markdown 格式](vocabulary_table.md)
- [CSV 格式](vocabulary.csv)

## 📖 单词表说明

单词表包含：
- ✅ 英文单词
- ✅ 中文翻译
- ❌ 已移除音标和星号标记

## 🛠️ 工具脚本

本仓库包含以下实用脚本：

- `process_words.py`: 从原始文本提取单词并生成 Markdown 表格
- `md_to_csv.py`: 将 Markdown 表格转换为 CSV 格式
- `create_pdf.py`: 将所有图片合并为一个 PDF 文件

## 📄 许可

仅供学习交流使用。

## ⭐ 如何使用

1. 下载 PDF 文件用于离线学习
2. 使用 CSV 文件导入到 Anki、Quizlet 等学习工具
3. 查看 Markdown 文件快速浏览单词
